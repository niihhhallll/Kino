# Shell For Linux 

## Information About My Project: KINO 
#### **This is a Linux/Unix Shell made from Scratch using C++, A shell is a program where it can execute commands,redirection queues,etc.**
## **What Does It Do?**
#### **Kino Provides users with Fancy looking UI,faster,lighter,easy to change UI.**


## **TECH STACK**
#### **The main languages Used in this Project Was C and C++, While the functions were mainly from C HeaderFiles.**

#### **This is a lightweight Program, So there weren't that much Cross-Compiling needed.**

## **Problems i encountred.**

#### **The main issue i encountred was how i can make the parsing logic, i kept coding for finding the optimal one. and from this issue i learned a lot about string parsing, and some weird bugs with getline function.**

## **How To Run Kino?**

1. Clone the source code to your pc
```sh
git clone https://github.com/niihhhallll/Kino && cd Kino
```

2. Install the project's dependencies
```sh
sudo apt install gcc cmake build-essential
```

3. Run the makefile
```sh
cd build && make
```

4. Run Kino
```sh
./Kino
```
